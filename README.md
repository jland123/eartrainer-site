# Ear to Ear

A competitive ear-training game: hear it, play it back.

**Play:** https://jland123.github.io/eartrainer-site/

This repository contains only the built website (generated files). Please don't edit it by hand;
it is overwritten on every deploy.

## Music and licenses

- All melodies are public-domain works (published by 1930 and composer died by 1955, or traditional).
  The site plays only the melody line with its own synthesizer: no recordings, lyrics or modern arrangements.
- The melody data in `content/content.v1.json` is derived from transcriptions by volunteers of the
  [Mutopia Project](https://www.mutopiaproject.org/). Each melody records its source and license; per-piece
  credits are listed in the site under **Settings → Credits**. Melody data derived from transcriptions under
  CC BY-SA is shared under the same license.
